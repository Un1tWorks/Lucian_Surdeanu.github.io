Customer Service RAG bot

Made with python and gemini help

It's an AI bot that answers customer service questions for the Raiffaisen bank.

This code powers a Streamlit banking assistant using Retrieval-Augmented Generation (RAG).

It retrieves relevant context from local files via ChromaDB vector search and passes it to Groq’s LLM to deliver accurate, source-cited customer support responses.
